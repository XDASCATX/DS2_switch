# tools/

Инструменты порта DS2: сборка (`build/`), запуск на ПК (`run/`), тулчейн Switch (`switch/`), разбор логов
(`analysis/`), codegen и анализ XEX (`*.py` в корне), исследование шейдеров (`shaders/`). Что делает каждый
файл — [../docs/reference/tools.md](../docs/reference/tools.md); как собирать — [../docs/build.md](../docs/build.md).

`nfsmw-legacy/` — инструменты порта NFSMW-NX, перенесённые как есть; в сборке DS2 не используются.
