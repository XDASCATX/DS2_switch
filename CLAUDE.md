# DS2 SotFS → Nintendo Switch

Текущее состояние — [docs/HANDOFF.md](docs/HANDOFF.md). История тестов — `docs/handoff/`.

Порт Xbox 360 TitleID `465307E4` на Switch: `Default.xex` → ReXGlue codegen → C++ + SDK → NRO; основной графический путь — нативный Vulkan/NVK.

## Правила владельца

- Отвечать по-русски и коротко; измерения отделять от гипотез. Цель — стабильные 30+ FPS без потери корректной картинки.
- `Default.xex` не менять. Игру, сгенерированный из игры код, NRO/ELF и дампы не коммитить; прошлые сборки не перезаписывать.
- Рабочая ветка `diag/switch-level-load`; `main` менять для release по просьбе владельца.
- Для RC: один краткий файл `RC-verNNN.md`, один TOML с ключами отката; собрать NRO и передать владельцу **без собственного игрового ПК-прогона**. Владелец проверяет на Switch и присылает отзыв/логи; только тогда делать вывод о скорости и стабильности. Подробные документы обновлять для release, не для каждой RC.
- Коммит тестовой версии: `vNN: <что>`; отправлять после проверки. Если рабочей среды сборки нет — не выдавать старый NRO под видом нового.

Версия v55 восстановлена как основа после неудачного теста v56. Актуальные ссылки и ограничения — в HANDOFF.
