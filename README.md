# DS2_switch

Порт Dark Souls II: Scholar of the First Sin (Xbox 360) на Nintendo Switch: статическая рекомпиляция (ReXGlue) и
собственный Vulkan-рендерер на NVK.

- Для ИИ-исполнителя: **[CLAUDE.md](CLAUDE.md)**, затем [docs/HANDOFF.md](docs/HANDOFF.md).
- Вся документация: [docs/README.md](docs/README.md). Для других ИИ-систем: [prompts/universal-handoff.md](prompts/universal-handoff.md).

Файлы игры, код, сгенерированный из неё, и собранные бинарники в репозиторий не входят.
