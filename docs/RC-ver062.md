# RC-ver062

Статус: разработка и отдельная сборка запущены; готового NRO пока нет. Цель — стабильные 60 FPS (16,67 мс), 30 FPS только промежуточный рубеж. Основа RC61: сохраняются исправления света/полосы, Mesa/NVK, разрешение и sample-space MSAA. Прошлые NRO/ELF не перезаписываются, игровой ПК-прогон и публикация не выполняются.

Crash: три отчёта RC61 имеют одинаковые 22 return offsets и адрес 0x82CB81D8. Добавлен отдельный 24-байтный thunk в `config/ds2_overrides.gaps.toml`; codegen в `app/generated/rc62` завершён, новый `sub_82CB81D8` зарегистрирован и содержит проверенный переход через vtable+40 с `mr r6,r7`. Исходный XEX не менялся. Это исправление discovery, не заглушка и не alias соседней функции. Подтверждение отсутствия вылета — только Switch-тест.

CPU: `ds2_native_cpu_cache` переиспользует неизменяемые upload slices констант/индексов внутри frame slot: checksum для поиска + полное сравнение байтов, ограниченный кэш, очистка после fence. Изменившиеся данные не перезаписывают старые slices. Descriptor writes/key используют сохраняющие capacity scratch-буферы. Добавлены счётчики hits/сэкономированных MB. Unit-тест совпадения, коллизий, изменения данных, границ и сброса пройден.

GPU: `ds2_native_vertex_inputs` — настоящий ограниченный путь `VkVertexInputBindingDescription`/`VkVertexInputAttributeDescription` с R32_UINT словами. Сохраняется существующий shader endian/format unpack; это НЕ полная предварительная конверсия в float. Допускается доказуемый безусловный vfetch-префикс r0.x, triangle list, проверенные indices/base/min/max/buffer bounds; неподдерживаемые случаи идут через legacy fetch. Новый shader modification и pipeline key содержат ABI/layout; shader/pipeline failure возвращает legacy путь. Реальное применение видно по `[native] vertex draws/frame`; наличие пути не доказывает долю использования или выигрыш. Исходные шейдерные шаблоны содержат stride0, игровые vfetch патчатся: число offline-eligible исходников не равно runtime coverage.

`ds2_native_alpha_specialization` убирает только динамический alpha test, когда guest comparison доказанно Always; исходные kill/alpha-to-coverage не удаляются. GPU-профиль разделён на бюджеты prepass64/material96/post32, чтобы prepass не занимал все timestamps. Удаления draw, снижения точности/разрешения/MSAA нет.

Библиотека: ABI13, новое имя `ds2_shaders_rc62.spvlib` и `.idx`, чтобы не смешать с RC60/61. Проверяются сигнатура самого pack до lookup, совместимость pack/index; причины промахов логируются. Host selftests индекса/подписи/повреждения пройдены. Пересборка и итоговая SPIR-V-валидация новых вариантов ещё выполняются; тестовые stride-патчи для проверки native ABI не включаются в игровой пакет.

Единственный TOML — `switch/rc-ver062/ds2.toml`. Независимый откат новых путей с перезапуском: `ds2_native_cpu_cache = false`, `ds2_native_vertex_inputs = false`, `ds2_native_alpha_specialization = false`; откат индекса и графических исправлений RC61 сохранён. Предварительная cross-компиляция renderer прошла. При параллельной компиляции большой generated register unit был остановлен OOM 4-ГБ VM; повторная сборка идёт одним компилятором. Итоговые проверки, native ABI tests, SHA-256 и состав комплекта будут записаны после завершения; 60 FPS не подтверждены.
