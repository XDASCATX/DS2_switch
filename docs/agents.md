# Роли ИИ-агентов

Проект ведёт один **координатор** (основная сессия ИИ), который общается с владельцем, принимает решения и выдаёт
версии. Отдельные роли нужны там, где работа объёмная и её результат можно вернуть кратко: разбор логов консоли,
поиск в коде, проверка изменений. Остальное координатор делает сам — лишние роли только тратят контекст.

Для Claude Code три роли оформлены как subagents в `.claude/agents/` (вызываются инструментом Agent). Другие ИИ-системы
могут использовать описания ниже как промпты ролей.

| Роль | Файл (Claude Code) | Когда | Вход | Результат координатору |
|---|---|---|---|---|
| Координатор | — (основная сессия; промпт для других систем — [../prompts/coordinator-system-prompt.md](../prompts/coordinator-system-prompt.md)) | всегда | запрос владельца, HANDOFF | версии, ответы владельцу, обновление документов |
| Аналитик логов консоли | `.claude/agents/console-log-analyst.md` | пришли логи `diag_tomlNN` | путь к логам, версия (для ELF), вопрос | таблица FPS/CPU/GPU по блокам, горячие функции потоков, рывки, вывод «где предел» с цифрами |
| Исследователь производительности | `.claude/agents/perf-investigator.md` | выбрать следующую оптимизацию | вывод аналитика, код рендерера | 2–4 кандидата с оценкой эффекта, риском и местом в коде (без правок) |
| Ревизор изменений | `.claude/agents/change-reviewer.md` | перед выдачей версии | diff, назначение версии | список рисков корректности/регрессий, проверки, которые надо сделать на ПК; сверка документации с кодом |

Поиск по коду — встроенный агент Explore Claude Code (отдельный файл не нужен).

## Правила взаимодействия

- Агенты **не правят код и не выдают версии** — только координатор. Агенты возвращают выводы с цифрами и ссылками
  на файлы/строки; помечают, что измерено, а что предположено.
- Координатор передаёт агенту конкретный вопрос и пути (агент не видит переписку).
- Результат агента, который меняет понимание состояния, координатор переносит в `docs/HANDOFF.md`,
  `docs/known-issues.md` или журнал `docs/handoff/18-native-renderer.md`.
