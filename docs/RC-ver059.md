# RC-ver059

Основа — RC58, тот же Mesa/NVK 26.2.4 с DS2-патчами. Оптимизация CPU: повторное использование неизменяемых наборов дескрипторов текстур/сэмплеров внутри кадра по полному ключу layout + image views + samplers + image layouts. Новые константы по-прежнему получают отдельные дескрипторы. Кэш очищается после ожидания fence перед сбросом descriptor pool; ранее записанные наборы не обновляются.

Откат: `ds2_native_texture_sets = false` в единственном `switch/rc-ver059/ds2.toml`, затем перезапуск. Добавлена строка `[native] draw detail ms/frame`: geometry, constants, descriptors, commands; число повторно использованных и созданных texture sets. Значения — части CPU draw, не складывать с GPU-временем.

Разрешение, MSAA, точность форматов, render area и драйвер не меняются; оптимизации RC57 не возвращены. Офлайн-библиотека шейдеров остаётся отдельной идеей. RC58 GPU занимает около 37–50 мс: ускорение CPU само по себе не гарантирует 30 FPS. Эффект кэша и корректность картинки должен подтвердить владелец на Switch; сравнить одну сцену после прогрева с ключом true/false. Первые игровые загрузки и компиляцию не смешивать с устойчивыми замерами.

Статус: NRO собран, комплект — `switch/rc-ver059/{ds2.nro,ds2.toml}`. Проверены ELF64/AArch64, точка входа `0x0`, сигнатура `NRO0` и совпадение SHA-256 после копирования: `abda184c966a6db542e5c8cc350b04967417e071455406e7568a1ffbed0e6ce2`.
