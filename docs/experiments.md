# Реестр версий и экспериментов

Каждая строка — одна выданная версия. **Коммит** — коммит ветки `diag/switch-level-load` с исходниками этой
версии (делался сразу после выдачи). **TOML** — `config/toml-history/<файл>`. **NRO** — sha256 из
`out/app-switch/releases/vNN/SHA256SUMS` (там же `ds2.elf` для символизации; до v35 релизы в этой папке не
сохранились). **Где проверено:** «консоль» — тест владельца на его Switch (логи `SW1_ds2/ds2_logs/diag_tomlNN/` на
его Mac, в git не входят), «ПК» — прогон в облачном контейнере (lavapipe), «—» — не тестировалась.

Результаты не переносить между строками: каждая строка — только про свою сборку. Исключение в столбце «Коммит»:
релизный пакет 0.56 помечен коммитом `main`/тегом `v0.56`, исходный код v56 — отдельно строкой ниже.

**Тестовый выпуск 0.56 = v56:** [GitHub prerelease](https://github.com/XDASCATX/DS2_switch/releases/tag/v0.56)
(2026-10-23, тег на `main` `d70c8eed`, **PRIVATE** по решению владельца). Исполняемая секция NRO побайтно
совпадает с v56; изменены только ASET-иконка и NACP (`xDASCATx`, `0.56`). TOML побайтно копирует v56,
sha256 `640795b195a7099738af51670a8a7b025146bd29c05f6c80e7742b7d01463e09`.
NSP-forwarder sha256 `c5887c1cc2caf6fa4d7875b04091fa590a1d1e1a49c4c1b137aa122c87ca2a0b`:
локально проверена структура PFS0 (3 NCA), ключи в открытом виде не обнаружены. SHA-256 всех четырёх
загруженных ассетов на GitHub совпали с локальными. **Консольный тест 0.56/NSP не проведён** — не переносить
замеры v55 на 0.56. Описание релиза — [../RELEASE_0.56.md](../RELEASE_0.56.md).

## Как добавить строку

После выдачи: версия, коммит, TOML, sha256 из `SHA256SUMS`, «ПК: …» если проверялось. После отзыва владельца:
«консоль (diag_tomlNN, частоты)» и результат его словами + замеры из логов (FPS, GPU мс, предел). Не менять
строки прошлых версий, кроме пометки «заменена vNN».
