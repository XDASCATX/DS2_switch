## Заголовок XEX2 (подтверждено разбором)

- Магия `XEX2`, title ID **`465307E4`**, оригинальное имя PE **`FRPG2.exe`**.
- Платформа 0, диск 1 из 1, media ID `458B3E06` — совпадает с хвостом XGD2 media ID в security-блоке.
- Filetime (из вывода codegen): **2014-11-26 11:32:08 UTC**.
- **Не delta XEX:** нет заголовков `0x4FF` (delta) и `0x80FF` (bound path), `module_flags = 0x1` (обычный title-модуль, биты патча не выставлены), `version == base_version` (обе 0x16, отображается как `0.0.0.22`). Базовый XEX для него не нужен.
- Шифрование **normal** (AES-128), сжатие **basic**. Три basic-блока: данные 0x1520000 + нули 0x1D0000 = 0x16F0000 (ровно размер образа); смещение данных 0x4000 + 0x1520000 = размер файла → файл не обрезан.
- Entry point **`0x829C3DE0`**, база и адрес загрузки **`0x82000000`**, размер образа **`0x16F0000`**, стек `0x40000`.
- Флаги образа `0x8` (только XGD2), регион `0xFFFFFFFF`, системные флаги `0x600`.
- TLS: 16 байт, адрес `0x83674E00`, два размера по `0x5B4` (совпадает с секцией `.tls`).
- Есть заголовки game ratings, LAN key, логотип. Поле timestamp/checksum `0x18002` присутствует, не расшифровывалось.
- Ресурс title в прошлом отчёте записан как адрес `0x83680000`, размер `0x6C291`. **Требует перепроверки:** по `0x83680000` позже обнаружилась секция `.idata` размером 0x508.

Всего 6,63 ГБ: папка `DS2` (5,47 ГБ) + два пакета.
