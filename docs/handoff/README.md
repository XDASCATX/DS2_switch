# DS2 SotFS (Xbox 360) → Nintendo Switch: передача проекта

> **Исторический документ (2026-10-19).** Текущее состояние — [../HANDOFF.md](../HANDOFF.md), индекс — [../README.md](../README.md).

Снимок состояния на 2026-10-19. Цель проекта — нативный порт Dark Souls II: Scholar of the First Sin (только версия Xbox 360, title ID `465307E4`) на Nintendo Switch через статическую рекомпиляцию PowerPC → C++. Техническая база — [NFSMW-NX](https://github.com/StevensND/nfsmw-nx) и её SDK ReXGlue.

## Где мы сейчас

| Этап (по исходному ТЗ) | Статус |
|---|---|
| 1. Обработка исполняемого файла | **Сделано.** XEX разобран, расшифрован, PE-образ извлечён и проверен |
| 2. Рекомпиляция кода | **Не пройдено.** Первый прогон `rexglue codegen` упал на валидации: 50 `UnresolvedCall` |
| 3–9. Запуск, движок, графика, геймплей, звук, 30 FPS | Не начинались |

Текущая задача — разобрать 50 ошибок по инструкциям и подготовить минимальные overrides. Разбор сделан (см. `05`), **overrides ещё не применены и codegen повторно не запускался** — по договорённости это делается только с отдельного согласия.
